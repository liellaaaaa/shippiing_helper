## 0. 一句话公式（全系统唯一）

```text
fill     = actual_fill_kg  if > 0  else 包装标称净重
packages = ceil(订单数量_kg / fill)          # 用了多少桶/袋就多少件，不管装多满
net      = 订单数量_kg                       # 有多少算多少，不放大不缩小
pallets  = ceil(packages / 每板件数)          # 打卡板时；不托/IBC = 0
           （可人工改托数；托数只计「真正用上的托」）
gross    = net + packages × 桶皮 + pallets × 托重
volume   = packages × 桶CBM + pallets × 托CBM   # 默认计算值，可被实测覆盖
```

**毛重定义（已确认）**：`毛重 = 净含量 + 桶皮 + 托盘`  
**净重定义（已确认）**：`净重 = 订单数量`（350kg 就是 350，不是 3×125）

## 2. 计算细则（已确认口径）

| 项 | 规则 |
|----|------|
| 净重 N.W. | **订单数量**，永不 = 件数×标称 |
| 件数 | `ceil(数量/fill)`，用了多少算多少，**不支持手改件数** |
| 桶皮 | `packages × tare`，**不管末桶装多少** |
| 托盘 | `pallets × 托重`；**托数=0 就不算托**（散货） |
| 毛重 | `净 + 桶皮 + 托盘` |
| 体积 | 默认 `packages×桶CBM + pallets×托CBM`；**可被实测覆盖**（单票 CBM 手填优先） |
| 备品 | **无**，严格订单量 |
| 合板 | 默认行独立 `ceil` 开托；**可勾合板**（同规格托合并） |
| 手改托数 | 表示少用/不用托；托重托体只计实际托数；货载体积毛重不按「板位」重算 |
| 海/空/陆 | 当前只做装柜判定；件数体积公式海运一套，后续空陆复用 |
| 精度 | CBM **3 位小数** |
| 旧数据 | 不自动改，打开计算器**提示重算** |

### 2.2 COA 与包装数据的关系（已说明）

| COA 字段 | 来源 | 与包装计算 |
|----------|------|------------|
| PRODUCT NAME | PI/台账品名 | 无关 |
| **QUANTITY** | **订单净重 = 发票数量 = N.W.** | **等于上文 `net`** |
| BATCH / 日期 | 检测报告/标签 | 无关 |
| 检测项 | 品质报告 | 无关 |

样例对账：HT260728A02 COA `QUANTITY: 360kg` = PL N.W. 360 = 订单数量；BLUETEC 合计 `500KG` = 各行 50×10。  
**结论：COA 的 QUANTITY 就用 `net`（订单数量），能对上，采用此逻辑。**
